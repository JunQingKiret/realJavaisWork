# 第一周教学大纲：基础语法与菜单启动

> 当前讨论稿 v0.2｜2026-10-12。依据教师反馈：学生目前主要会基础语法，尚不能独立编写类+集合+输入的小程序。D1–D7 是相对教学日，实际日期与课时待确认。旧版完整 V0 第一周任务已归档，不适用于本次起点。

## 1. 本周定位与边界

**从“认识语法”过渡到“独立组织输入、判断、重复与退出”。**

第一周只做校园二手商品程序的启动练习，不要求完整商品管理。菜单有三项：

- 1：输入一个商品名称，并回显“你输入的商品是：……”；这是输入练习，不表示已保存/发布。
- 2：显示一段教师指定的固定商品示例；这是输出练习，不是动态商品列表。
- 0：退出。

无商品类、集合、价格、数据库、Maven、HTTP、反射作业。可选介绍一个简单方法，但不作为本周过关项；方法的系统学习在第 2 周。

本周采用学生熟悉的 Java 8 风格语法，在拓展项目的 JDK 21 上运行。暂不要求 var、文本块、Record、箭头 switch。学校原有 Java 8 作业环境保持不变。

说明：Main 的启动类和标准入口形式可以由教师提供；Scanner 的创建和整行读取可以作为调用范例。这里“不引入业务类”不等于 Java 程序里不存在类或对象，而是不要求学生自行设计 Product 等业务类型。

## 2. 周末每人必须能做什么

1. 在自己的电脑上运行程序，区分编译问题和运行结果。
2. 从终端读取字符串，按输入选择不同分支。
3. 让菜单重复显示，输入 0 后正常退出。
4. 对未知选项和空输入给出提示，程序仍然能继续。
5. 独立修改一项选项/提示或输入规则，并实际验证。

Git 要求降为两次有意义的本地提交，可以由教师指导操作。不把远程账号、提交前缀、行数、新语法作为本周基础能力门槛。

## 3. 必讲与暂缓

| 本周必讲/练 | 暂缓 |
|---|---|
| 输出与字符串变量 | 商品对象设计、构造器、封装 |
| 用 Scanner 读取一行，名称含空格也能读完 | ArrayList、泛型、Stream |
| 字符串内容比较的最小用法 | 用整数解析菜单并引入异常体系 |
| if/else 或熟悉的普通 switch，统一一个起步写法 | 同时比较多种 switch 新写法 |
| while、继续下一轮、退出条件 | 强制方法拆分、完整调用栈讲解 |
| 空输入/未知选项，简单去首尾空白 | 金额、正则、复杂验证与业务异常 |

教学默认按字符串处理菜单：判断输入是否为 1、2、0，其他都提示未知选项。这样无需在第一周同时教授数值解析和异常捕获。老师讲字符串比较时，要让学生按范例使用并验证，不要求先掌握所有对象相等性细节。

## 4. 教师课前准备

- 一份只有启动结构的 Main 骨架，不含完整菜单逻辑；必要时包含创建 Scanner 的一行调用示例。
- 一个只用于现场演示的最终菜单程序，不提前发完整答案。
- 安装/运行简短说明：JDK、编辑器、Git；提前检查中文编码与输入。
- 熟悉学生学校 Java 8 配置，避免更改全局设置影响校内作业。
- 三个独立诊断小题和统一输入场景表。
- 两次指导、三次练习和一次验收的相对安排；如实际课时不足，优先减少材料和选做。

诊断小题只检查已学基础：

1. 输出一段欢迎文字并声明一个字符串变量。
2. 按给定变量值输出两个不同提示。
3. 用循环输出三次文字，解释什么时候停止。

如果做不了，不立刻转向类或集合；用本周时间补表达式、分支或循环。诊断不排名，不用“知道术语”代替会写。

## 5. 本周时间模型

| 活动 | 时长 | 说明 |
|---|---:|---|
| 指导 A | 75 分钟 | 诊断、环境、输入和单次分支 |
| 自主练习 A | 60 分钟 | 做输入和选择提示，暂不要求循环 |
| 指导 B | 75 分钟 | 循环、退出、空/未知输入、独立变式 |
| 自主练习 B | 60 分钟 | 完成循环菜单与输入名称 |
| 自主练习 C | 60 分钟 | 自测、修复、运行说明和验收准备 |
| 全组验收 | 30 分钟 | 3–4 人每人约 5 分钟，其余共性反馈 |
| **总计** | **6 小时/人** | 已包含记录和两次简短反馈，不追加每日站会 |

这些是暂定预算。若教师只能每周指导一次，应先确认是否改为更长周期，不能自动把第二次指导变成学生独立自学的新要求。

## 6. 第一次指导 A（建议 D1，75 分钟）

| 时间 | 教师活动 | 学生要做 |
|---|---|---|
| 0–5 分钟 | 演示三项菜单；说明输入练习与真正发布的区别 | 说出本周只做什么、不做什么 |
| 5–15 分钟 | 三项基础诊断，不计分 | 独立完成，老师记录实际缺口 |
| 15–30 分钟 | 检查运行环境，展示输出一个最小程序 | 每人运行成功，记录当前项目 JDK |
| 30–40 分钟 | 讲字符串变量和输出，用商品名称作例子 | 改一段输出和一个变量值 |
| 40–60 分钟 | 演示整行输入、单次分支，只选一种写法 | 自己读入字符串，输入 1/2/0 得到不同提示 |
| 60–70 分钟 | 脱离教师完整范例，做一次分支变式 | 增加一个临时选项或改提示，运行验证 |
| 70–75 分钟 | 说明自主练习 A、求助与材料范围 | 复述任务；不会的地方如实记录 |

如果环境未解决，不让学生靠抄别人截图交差。教师记录环境问题并安排短补运行确认；诊断结果仍保留。

## 7. 自主练习 A（建议 D2，60 分钟）

只要求单次输入与提示：

- 输出欢迎文字和菜单。
- 输入 1、2、0 时显示各自提示。
- 输入 abc 或 9 时显示“无效选项”。
- 运行一次后结束也可以；循环是下一次指导任务。
- 记录“做了什么、卡在哪、下一步”，只发一次简短反馈。

目前不做商品持久化、不处理价格、不要求 Git 操作已完全熟练。卡住 20–30 分钟后，提供最小错误和自己的尝试，及时求助。

## 8. 第二次指导 B（建议 D4，75 分钟）

| 时间 | 教师活动 | 学生要做 |
|---|---|---|
| 0–10 分钟 | 复盘输入与判断的共性卡点 | 独立展示一个分支结果 |
| 10–30 分钟 | 从“一次就结束”引出 while 和退出条件 | 菜单显示两轮，输入 0 后结束 |
| 30–45 分钟 | 按需求加入名称输入、空输入与未知选项 | 录入名称并回显；无效输入后还可继续 |
| 45–60 分钟 | 关掉完整范例，做一个小变式；结对只提供提示 | 每人自行修改一项提示/规则并验证 |
| 60–70 分钟 | 演示保存版本、看改动、暂存、提交 | 先提交当前可运行版；下一次修改后再提交 |
| 70–75 分钟 | 确认练习 B/C 和验收标准 | 列出未完成项，不用同伴代写补齐 |

共同讨论可以，但每名学生都要自己写、自己运行。不能按“甲写循环、乙写输入”拼一份程序来证明所有人掌握。

## 9. 自主练习 B/C

### B：建议 D5，60 分钟

- 菜单循环、选项 1/2/0、未知选项提示全部完成。
- 选项 1 输入商品名称，去首尾空白后回显；名称为空时提示并返回菜单。
- 选项 2 显示固定示例，之后返回菜单。
- 连续操作三次再退出，确认不是只运行一轮。
- 修复一个真实问题，保存第二次真实提交；不为凑次数制造改动。

### C：建议 D6，60 分钟

- 按下面的验收表自测，不通过就记录实际现象。
- 写最小运行说明：使用环境、怎么启动、已经完成什么、还有什么问题。
- 标记教师提供的启动结构/调用范例；不是所有代码都必须原创，但必须知道哪些逻辑由自己完成。
- AI_LOG：未使用 AI 就写未使用；允许概念解释和错误提示，不生成要提交的菜单功能。
- 发送第二次简短进度，准备现场口述；不强制录屏和多张截图。

## 10. 验收输入场景

| 编号 | 操作 | 预期行为 |
|---|---|---|
| T01 | 启动 | 欢迎文字和三项菜单显示 |
| T02 | 输入 1，名称为 Java 教材 | 回显完整名称，之后菜单再出现 |
| T03 | 输入 1，名称为空/全空格 | 提示名称不能为空，返回菜单，不假称发布成功 |
| T04 | 输入 2 | 显示固定示例，之后返回菜单 |
| T05 | 输入 abc、9、-1 | 提示无效选项；不会当作退出，不出现解析失败 |
| T06 | 菜单输入空白 | 提示无效选项，仍能继续 |
| T07 | 菜单输入前后有空白的 1 | 去空白后识别为选项 1 |
| T08 | 连续执行 1→2→无效选项→0 | 前三步均返回菜单，最后正常退出 |
| T09 | 输入 0 | 显示退出提示并结束，不继续显示菜单 |

本周选项 2 不是已保存商品列表。不要用“我刚输入的商品没有出现在列表”作为失败判据；保存多个商品将在第 2–4 周逐步实现。

## 11. 全组验收（建议 D7，30 分钟）

每人约 5 分钟：

1. 1 分钟：运行两项操作和退出。
2. 2 分钟：指出读取输入、判断分支、循环和退出分别在哪里。
3. 2 分钟：完成一个小修改并运行验证。

可用小改题：

- 修改选项 2 的固定示例和对应菜单提示，让说明与行为一致。
- 为选项 1 增加“名称最多 10 个字符”的判断，验证 10 与 11 个字符；老师允许给出长度读取的 API 提示。
- 在退出前多输出一行再见信息，并确认只在退出时出现。

现场不使用 AI，不要求未教过的方法、类或集合。改动未完成者说明卡点后短补验收，不让同伴替答。

## 12. 过关标准与评价

**本周硬门槛**：本人能运行、菜单可重复、0 正常退出、无效输入可继续、能解释并小改一个已教过的规则。

| 维度 | 建议分值 | 观察内容 |
|---|---:|---|
| 输入与不同分支 | 30 | 能读入、选择并显示预期结果 |
| 循环与退出 | 25 | 不只运行一次；退出条件正确 |
| 空/未知输入处理 | 20 | 提示后仍可操作 |
| 独立解释与小改 | 15 | 指出逻辑位置，修改后验证 |
| 版本与真实记录 | 10 | 保存真实进展，说明失败与脚手架来源 |

Git 暂未熟练不单独阻止进入第二周，但安排教师指导补操作。是否用新语法、代码行数、录屏效果不计为基本能力。

## 13. 教师复盘与下一周

记录每人：输出/变量、输入、分支、循环退出、独立修改、工具操作的状态。

- 多数通过：第 2 周进入方法和字符串，再用单个名称数组做列表/搜索。
- 一人卡住：给一个 20–30 分钟定向补练，替换其选做和材料时间，不把代写当帮助。
- 多数卡住：下一周继续补输入/循环；延后数组，调整总周期或删后期选做。

收尾问题：“现在只会回显一个名称。如果想保存三件商品、以后还能查到，程序还缺什么？”只讨论需求，不提前要求学生写 Product/ArrayList 答案。
