# 六题微诊断、答案与分层

诊断不计分。每题 1-2 分钟，可用腾讯会议投票或聊天区私发答案。

## 题 1：变量与输出

```java
String name = "螺丝刀";
System.out.println("物品：" + name);
```

问题：输出是什么？改成“物品：键盘”最少改哪里？

答案：输出 `物品：螺丝刀`；将变量值改为 `"键盘"` 即可。观察学生是否知道输出使用了变量，而不是要求同时修改两处。

## 题 2：字符串比较

```java
if (choice == "1") {
    System.out.println("查看物品");
}
```

问题：可能有什么问题？本课使用什么写法？

答案：菜单输入是字符串，内容比较使用 `"1".equals(choice)`。本节不展开引用相等与对象相等理论。

## 题 3：分支覆盖

问题：输入 `1`、`2`、`0`、`9` 分别走哪条路径？

答案：查看列表、进入搜索、退出、未知选项。观察是否遗漏默认分支，或把未知输入当作退出。

## 题 4：循环退出

```java
boolean running = true;
while (running) {
    // 菜单逻辑
}
```

问题：输入 `0` 时至少改变什么才能停止？

答案：在退出分支将 `running` 设置为 `false`。可接受使用 `break` 的解释，但课堂统一采用退出变量以便观察状态。

## 题 5：方法阅读

```java
static boolean containsKeyword(String item, String keyword) {
    return item.toLowerCase().contains(keyword.toLowerCase());
}
```

问题：接收什么、返回什么，`true` 代表什么？

答案：接收一个物品名称和一个关键字，返回布尔值；`true` 表示物品名称包含关键字，忽略大小写。

## 题 6：验证场景

问题：搜索已经能找到“螺丝刀”，还至少测试哪三类输入？

答案要点：部分关键字、找不到的关键字、空或全空格关键字。可补充英文大小写和前后空格。

## 分层记录

| 清楚题数 | 脚手架 | 本节最低要求 | 教师支持 |
|---:|---|---|---|
| 0-2 | 红色 | 菜单、分支、循环、退出、至少 3 个验证场景 | 可直接给 TODO 3 表达式，但学生须解释输入和结果 |
| 3-4 | 黄色 | 四个 TODO、独立局部修改、至少 5 个验证场景 | 只给 API 或语法提示 |
| 5-6 | 绿色 | 黄色任务加计数或方法拆分 | 用追问代替直接答案 |

分层结果填入能力矩阵，不在公开聊天区展示个人颜色。
