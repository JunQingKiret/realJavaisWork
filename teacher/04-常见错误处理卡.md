# 常见错误处理卡

## 先分类

| 类别 | 表现 | 第一检查点 |
|---|---|---|
| 编译错误 C | 程序无法启动，终端显示文件名和行号 | 看第一条错误、对应行和前一行 |
| 结果错误 R | 程序能运行，但行为与预期不同 | 写清输入、预期、实际，定位对应分支 |
| 环境错误 E | 找不到 `java`/`javac`、目录或文件 | `java -version`、当前目录、文件名 |

## 1. 使用 `==` 比较字符串

错误：

```java
if (choice == "1") {
```

本课统一写法：

```java
if ("1".equals(choice)) {
```

追问学生：这里要比较的是字符串内容，还是变量是否指向同一个对象？本节只要求记住内容比较写法。

## 2. 菜单只运行一次

表现：完成一次操作后程序结束。

检查：菜单逻辑外层是 `if (running)` 还是 `while (running)`。

最小验证：输入 `1 -> 1 -> 0`，确认菜单至少出现三次。

## 3. 无法退出

表现：输入 `0` 后仍显示菜单。

检查：退出分支是否执行 `running = false`；字符串比较是否写对；是否在别处又把 `running` 改回 `true`。

## 4. 搜索什么都找不到

检查顺序：

1. `keyword` 是否读取到实际输入；
2. `matches` 是否仍固定为 `false`；
3. `contains` 两侧是否都是字符串；
4. 英文大小写是否统一处理。

## 5. 找到结果后仍显示“未找到”

检查：匹配成功时是否执行 `found = true`；“未找到”判断是否放在整个循环结束之后。

## 6. 空关键字显示全部物品

原因：任何字符串都包含空字符串。

检查：搜索前是否先对关键字 `trim()`，并用 `isEmpty()` 提前返回。

## 7. 变量找不到或作用域错误

表现：`cannot find symbol`。

检查：变量是否在使用位置之前声明；是否声明在另一个 `{}` 块内；拼写和大小写是否一致。

## 8. 括号或分号错误

处理：先看第一条编译错误，不从最后一条开始修；检查报错行和上一行的 `() { } ; "` 是否成对。

## 统一求助格式

```text
我正在完成：
我输入了：
我预期看到：
实际看到：
第一条错误信息：

```
