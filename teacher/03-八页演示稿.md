# 第一节课八页演示稿

> 每个二级标题对应一页。投屏时只展示关键词和代码片段，详细口令见教师执行稿。

## 1. 今天的唯一目标

**能看、能改、能跑、能验证。**

- 看懂输入如何进入程序；
- 看懂分支和循环如何决定行为；
- 完成一个小改动；
- 用输入和结果证明改动有效。

今天不讲：WorkBuddy、Git 协作、Maven、完整 OOP、数据库、Spring Boot。

---

## 2. Java 程序的最短运行链

```text
WarehouseBasics.java
        ↓ javac
WarehouseBasics.class
        ↓ java
终端中的菜单与结果
```

遇到问题先判断：

- `C`：编译失败；
- `R`：能运行，但结果不符合预期；
- `E`：JDK、路径或启动环境有问题。

---

## 3. 输入进入变量

```java
Scanner scanner = new Scanner(System.in);
String choice = scanner.nextLine().trim();
```

- `nextLine()`：读取一整行；
- `trim()`：去掉首尾空白；
- `choice`：保存这一次输入。

问题：输入 ` 1 ` 后，`choice` 是什么？

---

## 4. 分支决定路径

```java
if ("1".equals(choice)) {
    // 查看
} else if ("2".equals(choice)) {
    // 搜索
} else if ("0".equals(choice)) {
    // 退出
} else {
    // 未知输入
}
```

每个已知输入有路径，未知输入也要有路径。

---

## 5. 循环负责继续，退出条件负责停止

```java
boolean running = true;
while (running) {
    // 显示菜单、读取输入、执行分支
}
```

退出分支：

```java
running = false;
```

问题：忘记修改 `running` 会出现什么现象？

---

## 6. 方法是一段有名字的任务

```java
searchItems(items, keyword);
```

阅读方法只问三件事：

1. 传入什么？
2. 方法做什么或返回什么？
3. 在哪里调用？

本节不要求独立设计业务类。

---

## 7. List 保存多项数据，for-each 逐项检查

```java
for (String item : items) {
    boolean matches = item.toLowerCase()
            .contains(keyword.toLowerCase());
}
```

搜索 `key` 时，四轮的 `item` 是什么？哪一轮匹配？

---

## 8. 先写预期，再运行验证

至少覆盖：

- 正常：`1`、搜索 `螺丝`；
- 异常：`9`、`abc`；
- 边界：空关键字、全空格、英文大小写；
- 流程：`1 -> 2 -> 9 -> 0`。

求助格式：输入、预期、实际、错误信息、已经检查过什么。
