第 2 课｜Agent 知识与仓库系统实战

本课目标
先理清需求，再尝试用 Agent 搭建仓库系统；逐步增加功能，在运行和验证中发现问题。

课前只做这三件事（约 20–30 分钟）
1. 打开上一课 Java 项目，尝试运行并记录卡点，约 5 分钟。
2. 浏览 01-课前预习手册.pdf，约 10–15 分钟。
3. 填写 02-仓库需求思考与课堂记录 的第 1 页，约 5–10 分钟。

文件怎么用
01-课前预习手册.pdf：阅读材料，共 6 页。
02-仓库需求思考与课堂记录.docx：直接填写的 Word 工作单。
02-仓库需求思考与课堂记录.pdf：同内容的 4 页打印版。
03-Agent提示词模板.txt：可复制的提示词，课堂按实际情况填写方括号内容。

工作单第 2–4 页在课堂填写，不是课前作业。
Word 和 PDF 工作单选一种即可，也可把第 1 页答案写在纸上。

带什么
电脑与充电器、上一课项目、填写后的第 1 页，以及一个想问的问题。

环境准备
沿用上一课 Java 环境。已有 AI/Agent 工具能用即可；尚未配置请记录，课堂可结对操作。
课前不要求安装 MySQL、创建 Spring Boot 工程、付费开通工具或申请 API Key。
不用提前把仓库系统生成出来。不确定的问题写“待确认”。

上课时间和地点以老师通知为准；课前填写结果带到课堂，无需在本资料中另找提交入口。
