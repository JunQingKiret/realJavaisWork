# 第 2 课：Agent 知识与仓库系统实战｜课前资料包

制作日期：2026-10-20。

本次采用教师最后确认的目标：先理清需求，再尝试用 Agent 搭建仓库系统，逐步增加功能，在过程中发现问题。参考第 1 课的学生材料结构和真实课堂内容；学生基础不预设为已经掌握 JavaWeb、MySQL 或工程搭建。

## 直接分发

- `lesson-02-agent-warehouse-student.zip`：发给学生的完整压缩包。
- `班群通知-可直接复制.txt`：教师可复制发送的群通知，本次没有代为发送。
- 不方便解压时，可以直接发学生目录中的预习 PDF 和工作单 Word；提示词模板可课堂再发。

## 学生需要做什么

课前总投入约 20–30 分钟：旧程序运行检查 5 分钟，手册阅读 10–15 分钟，工作单第 1 页 5–10 分钟。工作单第 2–4 页留在课堂填写。

学生准备一个真实或明确标注为假设的场景、三个需求问题、一项优先功能和环境状态。没有要求课前搭建完整系统、申请 API Key、购买工具或安装数据库。时间、地点及具体 Agent 工具未确定，材料没有编造这些安排。

## 教师可编辑材料

- `source/01-课前预习手册-教师可编辑版.docx`：手册的 Word 编辑版。
- `source/01-课前预习手册.md`、`source/02-仓库需求思考与课堂记录.md`：便于查看与修改的文字副本。
- `source/materials.json`：本次生成的结构化内容快照。
- `tools/build_materials.py`：包含权威生成内容与 PDF/Word 排版逻辑；修改脚本内内容后可以重新生成。重新生成会覆盖导出材料，已手工修改的 Word 应先另存。
- `qa/contact-sheet.png`：PDF 各页排版预览；逐页图片也在 qa 中。

PDF 和 Word 来源相同；PDF 是固定分页打印版，Word 因字体和编辑器不同可能自动重新分页。工作单每个阶段都写明课前或课堂用途，填写时以标题和提示为准。

## 教学边界

物品管理、登录、借还审批、库存调整、报表都列入整体需求讨论。物品查询只作为可选择的第一轮起点，最终范围由课堂甲乙方确认，不预先替学生作出所有决定。

本资料包不包含仓库应用源码或已验证的演示工程，不等于系统已实现。示例数据与提示词中的假设均已标明。没有附教师答案，学生资料不含本机路径、历史聊天链接或教师内部规划。

## 重建

构建使用 Python、python-docx、ReportLab、pypdf、pypdfium2、Pillow 和 Windows 黑体字体。当前会话已用随应用提供的运行环境生成并检查。

```powershell
python tools/build_materials.py
python tools/package_materials.py
```

重建后先重新检查排版，再运行 package_materials.py 核对内容并打包 student 目录。压缩包不包含 source、tools、qa 和教师说明。
