## 已知情况与暂定条件

- 面向 3–4 名正在学习学校 Java 8 专业课的学生；不是替代校内课程。
- 教师判断：学生目前主要掌握基础语法，尚不能独立编写包含类、集合和输入处理的小程序；第一周用独立练习进一步确认，不把这一判断当作已经完成的测试。
- 教师列出的面向对象、集合泛型、异常、Maven、JDBC/SQL、HTTP/JSON、反射注解，需要纳入学习与检查；不将这些内容认定为学生已经掌握。
- 保留校园二手交易项目方向；先做小练习，再逐步整合成项目。V0–V6 是演进标记，不是必须按旧周次赶完的任务。
- 第一周目标降为菜单、输入、分支、循环、退出；不要求商品类、集合、价格处理、发布列表搜索全部完成。
- 当前推荐讨论路线为 16 周：6 周基础整合、3 周数据库、2 周 HTTP/JSON 与注解认识、5 周 Spring Boot。
- 16 周只是建议，未获教师确认；原 12 周稿保留对照。若周期必须为 12 周，应降低结业范围，而不是原任务等比例压缩。
- 每人每周暂按 5.5–6 小时课外总投入，包含教师指导、自主练习与验收；实际课时待确认。
- 前期每人独立练习、结对排查；通过基础整合关卡后再维护小组主仓库，避免一人代写。
- 尚未生成完整教学项目、学生答案或教师脚手架；先共同确认安排。

## 边界

- 学习目标是能够解释、独立修改和验证，不以覆盖技术清单为完成标准。
- 初期使用 Java 8 风格的熟悉语法，在拓展项目的 JDK 21 环境运行；学校 Java 8 环境不改。
- 教学项目只用虚构商品和身份，在本机运行，不涉及真实支付、公网生产部署或真实学生信息。
- 框架版本候选与支持状态见资料文档，开课前仍需验证统一版本；本轮没有进行实际工程构建验证。
